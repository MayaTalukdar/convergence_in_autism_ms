This repository contains all scripts needed to replicate the analysis of Andersen and Talukdar et al. Demo scripts to show how to run scripts in this repository 
can  be found in Figure_1_And_S1 > Figure_1C_Enrichment_Barplot_DEGs. 

Additionally, this repository also contains a catalog of the differentially expressed genes identified in this manuscript across various experiments. They can be found as follows:
(1) DEGs identified from CRISPR-Cas13 KD of ASD genes in NPCs: 0_Figure_1_And_S1_And_S2_And_S3/Raw_Seq_Data_Processing_And_Differential_Expression_Analysis/1_Run_Differential_Expression/DEG_Results
(2) DEGs identified from shRNA KD of ASD genes in NPCs: 2_Figure_S5/1_Process_shRNA_Data/DEG_Results
(3) DEGs identified from re-analysis of CRISPR-Cas9 KO of ASD genes in IPSCs and ExNs (PMID: 30392976): 2_Figure_S5/0_Process_Deneault_Data/differential_expression_analysis/DEG_Results
(4) DEGs identified from differential expression analysis of long-term and acute KD organoids: Figure_3_And_S8/Organoid_DEG_Supplementary_Tables
