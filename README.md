# Andersen and Talukdar et al. — Analysis Repository

This repository contains all scripts and supporting files needed to **replicate the analyses presented in Andersen and Talukdar et al., Nature 2026**

## Repository Overview

The repository includes:

* Scripts used to process and analyze the data presented in our manuscript 
* Demo script illustrating how to run scripts in this repo
* Intermediate files required for reproducibility that are not generated directly by the provided scripts
* Catalogs of differentially expressed genes (DEGs) identified across the experiments described in the manuscript

> **Note:** Many scripts contain file paths specific to the authors' file server system. Before re-running analyses, please update these paths to reflect your local environment.

---

## Getting Started

Demo scripts are provided to illustrate how to run the analysis pipeline.

For examples of how to reproduce the analyses associated with **Figure 1C**, see:

```text
0_Figure_1_And_S1_And_S2_And_S3/
└── 0_Figure_1C_Enrichment_Barplot_DEGs/
    └── Demo/
```

These demo scripts provide examples of how to configure and run the corresponding analysis scripts, including how to use these scripts on a Slurm server.

## Reproducibility

To facilitate reproducibility, this repository includes **intermediate files that are not directly generated by the provided scripts**, including files such as sample keys and other analysis inputs.

However, some scripts reference software installations, output directories, and file paths specific to my computational environment. These paths **must be updated before running the analyses on your system**.

If you are reproducing an analysis, we recommend reviewing the relevant script for:

1. Input file paths
2. Output directories
3. Software and package dependencies
4. Reference files
5. Sample metadata and keys
